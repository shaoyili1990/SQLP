第五卷：鬼灭之刃·修正之旅

序章：权限与夫管严

幻音坊，内殿。

李茂贞开门见山："本王希望，能够去其他的世界看一看。"

作为张平凡的大舅哥，岐王这次请求有备而来——他已经从昭昭那里听说了"万界旅游"的计划，也对这个能突破时空界限的能力产生了浓厚兴趣。

张平凡自然没有拒绝。他在笔记本的权限列表中添加了李茂贞的名字，级别设为昭昭的下级。

处理完大舅哥的事，女帝忽然开口："我需要一些千里传音。"

"赵恒？"张平凡下意识地看向昭昭，有些奇怪——这事昭昭就能解决。

女帝转过头，用一种极度不爽的眼神盯着昭昭，一字一句地说："这位'张家媳妇'说了，这种事情，需要先问过你这个'一家之主'才行。"

然后，她狠狠地瞪了张平凡一眼。

张平凡苦笑："行行行，给您加权限。"

他在笔记本上写下女帝的名字，级别与昭昭同级。权限搞定后，女帝的脸色才缓和下来，露出了一丝满意的神色。

然而一旁的昭昭，在看见张平凡给女帝也开通了权限后，脸上又露出一丝微妙的表情——不是满意，也不是生气，而是某种"这家伙怎么随便给人开权限"的微妙幽怨。

"这又怎么了……"张平凡心中暗道，却不敢问出口。

 Chapter one：修正指令

现代世界，公寓。

张平凡坐在书房里，神情前所未有地严肃。

在他面前摊开的笔记本上，清晰地记录着一段他一年前没有料到的操作日志：

```
【使用者：黄蓉】
【操作：跨世界介入鬼灭世界（时间点：第一日第二天）】
【行动内容：
  1. 使用紫外线灯与鬼杀队合作，消灭鬼舞辻无惨
  2. 向珠世提供生物医学知识，建立改良研究
  3. 建立八重村，推动人与鬼共生的社会实验
  4. 重组部分鬼杀队成员为'民间除灵组织'
  5. 向产屋敷家提供'现代化医疗方案'
】
【世界线偏移：+1年】
```

张平凡的手指在日志上轻轻敲击。

"+1年。"他低声自语。

蓉儿的介入，不仅仅是"杀了一个无惨"那么简单——她的整个"现代化介入"，将这个世界的"历史节奏"往前推了整整一年。

原著中原本应该发生的剧情线——无限列车篇、游郭篇、刀匠村篇、最终决战篇——现在都失去了原有的时间框架。在这个提前了一年的世界，许多原本应该还在酝酿中的事件，已经或即将提前发生。

"txt，打开系统日志。"他对着笔记本说。

笔记本无风自动，页面刷新，显示出更详细的世界状态扫描：

```
【鬼灭之刃世界 · 偏移报告】
├─ 主线偏差：37%
├─ 角色状态：
│  ├─ 产屋敷耀哉：寿命延长（生物制剂介入）✅
│  ├─ 珠世：生物医学水平提升 ✅
│  ├─ 愈史郎：存活（未遇险）✅
│  ├─ 鬼杀队：重组为民间组织 ⚠️
│  ├─ 猗窝座：时间线变动，出现时间待确认 ⚠️
│  ├─ 上弦之鬼：部分存活，部分被引渡 ⚠️
│  └─ 无惨：已确认死亡 ✅
├─ 新增势力：八重村（人鬼共生实验区）🆕
├─ 新科技：蒸汽火车、现代医疗、紫外线灯 🆕
└─ 风险评估：中（短期可控，长期剧情线未知）
```

张平凡的手指在"风险评估：中"上轻轻划过。

"不会只有中等。"他低声道。

他将笔记本翻到最后一页，夙兴夜寐地写下这次任务的每一个步骤：

```
任务书：鬼灭世界修正之旅
目标：评估偏移影响，维持世界稳定，避免剧情崩坏
手段：
  1. 不暴露跨世界干预的全部真相
  2. 与珠世和产屋敷谈判，争取理解
  3. 回收原时间线"被跳过"的核心事件（猗窝座、游郭篇）
  4. 确保鬼灭世界最终走向"正确的结局"
限制：不强行抹除已有成果（八重村、改良医学）
```

写完，他用钢笔在末尾补了一行字：

"附加：弄清楚蓉儿这一年到底做了多少我授权以外的事。"

 Chapter two：再临鬼灭

坐标启动。

光芒笼罩，空间扭曲。

张平凡的身影在鬼灭世界的夜空下显现。他选择了袭击——不是漫画里的初始小镇，而是八重村外围的一处山林。

落地之后的第一件事，就是观察环境。

远处，八重村的灯火在夜色中并不明亮——比起现代都市，这里更像是"近代化实验村"。他站在山顶，用笔记本的望远镜功能远眺，看到了村口的石碑：

"人与鬼，共存之试。"

"壮观。"张平凡轻声道。

原文这**不是**他的语言，而是某种他无法控制的本能反应。看来他的穿越体质对这个世界有了某种"适应性"——不再像上次那样刚落地就引起空间涟漪。

他平稳落地，向村庄潜行。

还未靠近，便察觉到一股令他不安的气息——不是鬼气，而是一种更阴冷、更粘稠的东西。像是……诅咒的回响。

他停住脚步，目光锁定前方的一个方向。

三公里外的一座小山上，一座废弃的神社若隐若现。

他认出了那座神社——这是原著中鬼杀队曾经的一处据点，也是灶门炭治郎第一次发现"十二鬼月"相关线索的地方。

但这座神社的"状态"，和他记忆中不同。

神社的屋顶坍塌了一半，鸟居倒在泥水里，但最令人毛骨悚然的是——神社周围的树木，全部是"倒着生长的"。树根朝天，枝叶入土，扭曲的枝干像一只只挣扎的手。

"啧啧，看来这里发生过比无惨还离谱的事。"

 Chapter three：与珠世的谈判

张平凡没有直接去八重村，而是选择了先去那座"异常神社"。

他想先搞清楚这个"偏差"的来源——如果偏差是"从某处开始扩散"的，那这座神社，很可能是原点。

踏入神社范围的瞬间，他的每一步都像踩在刀尖上——不是痛，而是"存在本身在被排斥"的感觉。

神社内部，已经彻底荒废。正殿的神龛被砸碎，供桌翻倒，地面上的符咒画满了奇异的花纹，看起来像某种"失败的封印"。

但在正殿中央，一个人影正背对着他站着。

"你来了。"那个身影没有回头，声音平静。

张平凡认出了这个声音——不，准确地说，是他"感应"到了这个声音的主人。

珠世。

"你在这里做什么？"张平凡一边问，一边放低重心，随时准备应对。

"等你。"珠世缓缓转过身，血色的瞳孔在昏暗的光线下如同两盏灯笼，"一年了。我从那个春天等到现在，你终于来了。"

"你知道我会来？"

"蓉儿告诉我的。"珠世从神龛旁走出，白裙曳地，银发如霜，"她说，如果我等到一个自称'雷梦杀故人'的人出现，那就是'修正者'。"

张平凡的瞳孔微不可察地一缩。

蓉儿……你到底留了多少后手？

"她有说'修正者'是谁吗？"

"没有。"珠世摇头，"她只说，'他长什么样子我不清楚，但他一定会在某一天出现。他会拿着一个'本子'，会自称是雷二的故人。然后，他会做一些'看起来没事但实际上很危险'的事。'"

张平凡："……"

他忽然觉得蓉儿比他想象得更深不可测。

"不管你是谁， oder 什么目的。"珠世走近了两步，血色的瞳孔直直地盯着他，"我只想知道一件事——你是不是这个世界的'异常'？"

"你觉得呢？"

"我觉得你和蓉儿有关。"珠世的声音平静但不容错辨，"蓉儿是一年前突然出现的。她出现后，这个世界'偏差'就开始扩散。如果你是来找她的，那——"

"我来找的确实是她。"张平凡坦诚，"我也确实要'修正'一些她带来的偏差。"

"那你就是'异常'。"珠世一字一句地说。

张平凡笑了笑，没有反驳。

"对。我可以承认。"

珠世的瞳孔骤然收缩。

"但我不是在制造异常，我是在修正它。"张平凡抬起手，用绘图笔在空气中虚画了一下——没有任何特效，只是纯粹的示范动作，"蓉儿提前一年进入了这个世界，她做了很多好事——建立医疗系统、改良鬼族生物学、推动人与鬼的共生。这些本身没有任何问题。"

"但问题是，她'快进'了这个世界的节奏。原本应该在一年后发生的事件，现在已经提前了。而因为这个'快进'，一些关键人物的命运线开始松动——虚弱产屋敷没有病死，猗窝座的变强路径被打乱，上弦之鬼的排名面临重新洗牌——这些都是她没有料到的'蝴蝶效应'。"

珠世沉默了很久。

"那你打算怎么做？"

"我不打算抹除蓉儿创造的东西。"张平凡说，"八重村留下来，改良医学留下来，珠世医术 advancements 留下来。这些是好事。"

"我只是需要把'剧情线'拉回正轨——让那些该发生的事情，以正确的时间顺序发生。不提前，也不延迟。"

"比如？"

"比如——猗窝座的'转折点'，还要再等几个月。游郭篇的'上弦之六'，要在正确的时机才登场。还有……"

张平凡没有说完。

但珠世从他的沉默中读出了某种她没有问出口的东西。

"你不用告诉我全部计划。"她轻声说，"但是张平凡——"

"我有一个条件。"

"什么？"

"让愈史郎，离开这个世界的核心。"

张平凡微微一愣。

"愈史郎 possesses 你想不出来的' historia '。"珠世血色的瞳孔中流露出一丝复杂，"如果他留在'主线'中，他的命运会变得不可预测。而我……不想再失去他第二次。"

张平凡看着她。

她不是在请求，她是在警告。

"好。"他点了点头，"愈史郎跟我走。我会安置他到雪月城。"

珠世的瞳孔中闪过一丝他并未读懂的情绪。

"他如果知道我要把他'送人'，一定会大闹一场。"

"那是你的问题。"张平凡笑了笑，"我只要结果。"

 Chapter four：回收与安置

珠子条件达成后，张平凡立刻着手两件事：

第一，与产屋敷面谈，获取正式认可。

第二，回收"偏移线"上的关键人物——首先是愈史郎，然后是其他"因偏移而提前出现"的角色。

都不是轻松的活。

产屋敷方面，比他预想的更顺利。老人听完他的"跨世界解释"后，没有震怒，也没有质疑，而是沉默了很久。

最后他只问了一个问题：

"那个叫'蓉儿'的姑娘，她还活着吗？"

"在。"张平凡回答。

"那就够了。"产屋敷缓缓起身，"只要她好好的，这个世界的未来，我可以赌一把。"

张平凡知道他说的"赌"是什么意思——产屋敷把"跨世界存在"看作是一种新的"命运"。他选择接受，不是因为相信张平凡，而是因为他看到了蓉儿所留下的、那些实实在在的"好事"。

"你走吧。"产屋敷最后说，"但记住——如果你对她不利，就算跨越了世界，我都会追到你面前。"

张平凡没有接这个狠话，只是点了点头，离开了。

愈史郎的回收则是另一种画风。

他显然已经听到了风声——珠世和产屋敷的私下交谈他多少知道一些——在张平凡踏进八重村的瞬间，他就已经在村口等着了。

"你要把我带去哪里？"他的语气暴躁又警惕。

"雪月城。"

"那是什么鬼？"

"我那边的世界。安全，有吃有喝，有住有睡。"张平凡耸肩，"总比留在这个世界随时可能被卷进战斗里强。"

愈史郎沉默了一会儿，忽然冒出一句："珠世大人同意吗？"

"她让你跟我走。"

"你自己说的？"

"她说的。"

愈史郎又沉默了。

过了许久，他才闷闷地开了口："那……珠世大人会来看我吗？"

"会。"

"多久一次？"

"想清楚了——你去了我的地盘，你是我的客人，不是她的病人。她没有理由来看你。"

愈史郎的脸绿了。

"开玩笑的。"张平凡拍了拍他的肩膀，"我的世界很大，有医术比她更高的医生。你想见她的话，我可以安排她来做客。"

愈史郎这才脸色稍霁，嘟囔了一句："你最好是。"

 Chapter five：新威胁

一切尽在张平凡的掌控中——直到他回到笔记本前，翻到了最新记录。

日志上多了一条他没有录入的信息：

```
【检测到未知势力介入】
【代号：千年宗】
【活动区域：八重村北侧山脉】
【特征：使用禁术"鬼进之术"制造半人半鬼的战士，
      与鬼杀队的"退魔科技"存在直接对抗关系】
【危险评估：高】
```

张平凡看着这行字，眉头紧锁。

"千年宗"——这不是原著中的任何势力。

ri, 它像是从某部同人作品里走出来的反派组织，专精于"以鬼制鬼"的禁术，崇尚" lords of the night"的理念。

但(log)最令人不安的是，这个组织的出现，与蓉儿的"偏差"在时间线上高度吻合——它出现的时间，恰好是蓉儿介入后的第二个月。

也就是说——

"不是因偏差而产生的后果，而是——"

"有人趁偏差之机，引入了'原本不存在于此的变量'。"

张平凡的瞳孔骤然收缩。

"千年宗"不是世界自身的产物。它是某个"更高层级的干预"所植入的。

而这"更高层级的干预"，与他的笔记本、与蓉儿的横空出世，极有可能——

"同源。"

他把手按在笔记本封面上，感受着那股熟悉的、微微发烫的触感。

"这个世界不对劲的地方，比我预想的多得多。"

 Chapter six：交火

 Millennium Sect（千年宗）的第一次正式接触，发生在八重村外的废旧铁路线上。

张平凡本不该出现在那里——但他总有某种直觉，像一只无形的手在拨动他的行动方向。当他站在废弃车厢旁，看到远处山坡上那些人时，他"料到了"。

但没料到的是，他们的装备如此精良。

"那是……枪？"张平凡有些意外。

在这个世界，火枪是存在的，但受限于"刀才是正道"的武学观念，火器几乎没被认真开发过。眼前的这些人，却配备了改良过的火绳枪，以及……一些明显不属于这个时代的部件。

"驱动机关……还有电池？"张平凡眯起眼睛——"不对，这不是电池，这是某种'灵质电池'。也就是某种 '非人类标准品'。"

"你是什么人？"为首的一个黑衣人厉声喝道，手里的枪口对准张平凡。

"路人。"张平凡没有动，"你们又是什么人？"

"这个你不用管。"黑衣人冷笑道，"带走他。他看起来和那个'黄蓉'是一伙的。"

张平凡听到这个名字，心了然。

千年宗的目标不是鬼，也不是普通人——他们的目标是所有与"跨世界干预"有关联的人。

蓉儿。珠世。产屋敷。愈史郎。以及——他本人。

他叹了口气。

"本来不想太早暴露。"他用另一只手掏出了笔记本，快速翻开一页，"你们自己撞上来的。"

下一秒，他用笔在笔记本上写下了一句简短的话：

"Target：千年宗前哨站。Effect：重力领域·局部。"

话音落下，以张平凡为中心半径五十米内，空气忽然变得粘稠——重力像水银一样，将所有人都压得弯下了腰。黑衣人手中的枪掉落地上的声音此起彼伏。

"什么？这是什么术式？"黑衣人惊恐地喝道。

"不是术式。"张平凡走到他面前，居高临下地看着他，"是物理。"

他的声音很平静，但每一个字都像铁锤砸在黑衣人脸上：

"你们最好告诉我，千年宗背后的主使是谁。以及——"

"你们是怎么知道'跨世界'的。"

 Chapter seven：棋子的答案

张平凡没有杀人。

他只是用笔记本制造的"重力场"短暂地压制住了所有人，然后用藤蔓捆住了他们（这招是从射雕世界的黄蓉那里学的）。

然后他把带头的黑衣人带到了附近的空地，单独审问。

"名字。"

"……常吉。"

"好，常吉。我来问几个问题，你回答。"

"不说。"

张平凡笑了笑，用钢笔点了点笔记本封面："你认为，我有一万种方法让你说。但你最好自己选——是哪一种？"

常吉的脸色变了。

"千年宗是什么组织？"

"是……是教派。我是下层成员，只听命行事。"

"谁的命令？"

"宗主的。"

"宗主是谁？"

常吉犹豫了一下。

"说出来就放过你。"

"……是'它'。"

"啥？"

"不是'他'。"常吉的声音变得极其诡异，"是′它′。一个……不是人的东西。"

张平凡的眉毛挑了起来。

"千年宗的宗主，不是人类？"

"传言说，它是从'另一个时空'来的。"常吉的声音开始颤抖，"它给了我们技术和知识，让我们建立这个组织。它说——'当这个世界的偏差达到某一阈值，它就会醒来'。"

"它什么时候醒来？"

"不知道。但它说——"常吉抬起头，用最后的力气说——"'先干掉黄蓉，一切才能回到原点。'"

张平凡心中轰然一声。

这不是同谋。

这是一个"更高层级的对手"——一个同样来自其他世界的存在，一个与他的笔记本"同源"、却目的相反的存在。

而那个存在，自称：

"它。"

 Chapter eight：卷五终——裂痕

审问结束后，张平凡把常吉"放了"。

不是出于仁慈，而是因为他知道，放他回去，千年宗才能大批暴露——而大批暴露，才是他真正想要的。

现在他需要重新梳理整个棋局：

棋盘的初始状态：一个原本平平无奇的鬼灭世界。

第一枚棋子落下：张平凡的笔记本，打开了跨世界通道。

第二枚棋子落下：蓉儿提前一年，带着现代知识介入。

棋盘开始扭曲：世界线+1年，八重村建立，生物医学革新，鬼杀队解散。

第三枚棋子落下：千年宗出现——一枚"反向棋子"。

它的目标：阻止一切改动，把世界"重置"到最原始的时间线。

它的背后：某个同样来自"外部"、但与张平凡的笔记本相互排斥的存在。

张平凡坐在八重村的屋顶上，夜风从山谷中吹过，带着山下大海的咸味。

他在笔记本的最新一页，画了一个棋盘。

白棋是他和他的人。黑棋是千年宗，以及某种更庞大、更黑暗的东西。

"这个游戏，不只是'乐子'了。"

他低声自语。

然后他在笔记本上写下：

"最终目标：谁在棋局的背后？"

"而那个'它'——又是什么？"

"这个世界，正在分裂。"

"而我将成为——那个缝合裂缝的人。"

风起了，将他的衣袍吹得猎猎作响。远处的海面上，月光洒下，波光粼粼。

一切还是那么美。但如果他"看不见"的暗处，无数裂痕正在蔓延。

第五章。一场修正。一个秘密。一个开始。

（卷五·完）

这一卷的核心转折点是：揭示了万界世界观里存在着"对立的高维存在"。

蓉儿的"热心过头"意外引爆了这个隐患。

而千年宗的"宗主"——那个自称"它"的存在——究竟是谁？
